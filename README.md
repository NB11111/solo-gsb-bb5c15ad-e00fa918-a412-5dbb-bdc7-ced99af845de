# 多设备事件对时 · 现场排障时间线

现场排障场景下，经常需要把多台设备（摄像机、NVR、网关、服务器……）各自导出的
JSONL 事件流对齐到同一条时间线。各设备时钟常有固定偏差和走速差异，本工具通过
**“本地时间 → 基准时间”锚点**做**分段线性校时**，再合并成统一时间线，并标出锚点
覆盖区间之外的**外推事件**。

- 后端：Node.js + Express（校时算法前后端共用、零额外依赖）
- 前端：原生 HTML / CSS / JavaScript，无需构建
- 支持多设备、每设备多锚点、原始/校正时间切换、合并 JSONL 导出
- 提供 Dockerfile 与 docker-compose，**一条命令启动**

## 使用步骤

1. 点击 **＋ 添加设备**，填写设备 ID（如 `cam-a`）和可选备注名。
2. 在每个设备卡片中粘贴 JSONL 事件流（**每行一个 JSON 对象**）。事件中的时间字段
   按以下优先级识别：
   `ts` / `time` / `timestamp` / `@timestamp` / `eventTime` / `logTime` / `datetime`，
   值支持 **ISO 8601**（如 `2026-09-21T10:00:00.000Z`）或 **epoch**（秒/毫秒，数字或纯数字字符串）。
3. 为每台设备添加至少一个同步锚点，格式：`本地时间 → 基准时间`（两种时间格式同上）。
   建议在排障窗口首尾各取一个锚点。
4. 点击 **开始对时**：
   - 系统按本地时间对锚点排序；
   - **相邻锚点之间做分段线性插值**；
   - 首/尾锚点之外的事件按最近一段斜率**外推**，行底色与「外推·锚前 / 外推·锚后」标记会高亮提示；
   - 只有一个锚点时按固定偏移整体平移（锚点之外同样标记为外推）。
5. 在结果区可切换 **校正时间（基准）/ 原始本地时间** 视图，点击
   **⬇ 导出合并 JSONL** 下载按基准时间排序的合并文件。

也可以点击顶部 **载入示例** 快速体验（含两台存在时钟偏差的设备和区间外事件）。

### 输入示例

事件流（JSONL）：

```jsonl
{"ts":"2026-09-21T02:10:00Z","level":"motion","msg":"detected @gate"}
{"ts":1789237215123,"level":"snapshot","msg":"saved"}
```

锚点：

| 本地时间 | 基准时间 |
| --- | --- |
| `2026-09-21T02:00:00Z` | `2026-09-21T02:05:00Z` |
| `2026-09-21T03:00:00Z` | `2026-09-21T03:05:06Z` |

## 校时与校验规则

- **分段线性校正**：设相邻锚点为 `(L0, B0)`、`(L1, B1)`，对本地时间 `t`：

  ```
  corrected = B0 + (t - L0) * (B1 - B0) / (L1 - L0)
  ```

  该模型同时吸收固定偏移与走速差（斜率 ≠ 1）。
- **锚点校验（拒绝条件）**：
  - 锚点必须**按本地时间升序依次填写**（输入顺序即锚点顺序，系统不做自动重排）；
  - 锚点的本地时间必须**严格升序**（重复或倒序拒绝）；
  - 对应基准时间也必须**严格升序**（倒序/重复拒绝，防止时钟倒流的锚点）；
  - 锚点必须成对填写，只填一端会被拒绝；
  - 包含事件的设备**至少需要一个锚点**。
- **外推标记**：事件本地时间早于第一个锚点 → `外推·锚前`；晚于最后一个锚点 →
  `外推·锚后`。外推结果可信度低于锚点区间内的插值，现场使用时请结合实际判断。
- 无法解析为 JSON、不是对象、缺少时间字段或时间无法解析的行会被跳过并在结果区
  逐条列出（设备 + 行号 + 原因），不影响其余事件对时。

## 导出格式

导出的 `.jsonl` 每行对应一条事件，按校正后的基准时间升序排列，**原始字段全部保留**，
并附加以下元数据字段：

| 字段 | 含义 |
| --- | --- |
| `_deviceId` | 来源设备 ID |
| `_localTs` / `_localIso` | 原始本地时间（epoch 毫秒 / ISO） |
| `_correctedTs` / `_correctedIso` | 校正后基准时间（epoch 毫秒，可能含小数；ISO 四舍五入到毫秒） |
| `_extrapolated` | 是否落在锚点覆盖区间之外 |
| `_extrapolationSide` | `before` / `after` / `null` |

## HTTP API

- `GET /api/health` — 健康检查
- `POST /api/align` — 对时合并

请求体：

```json
{
  "devices": [
    {
      "id": "cam-a",
      "name": "大门摄像机",
      "anchors": [
        { "local": "2026-09-21T02:00:00Z", "base": "2026-09-21T02:05:00Z" },
        { "local": "2026-09-21T03:00:00Z", "base": "2026-09-21T03:05:06Z" }
      ],
      "events": [{ "ts": "2026-09-21T02:10:00Z", "msg": "motion" }]
    }
  ]
}
```

锚点非法时返回 `400` 与中文错误说明。
